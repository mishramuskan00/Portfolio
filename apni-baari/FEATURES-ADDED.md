# अपनी BAARI Frontend Upgrade

The existing visual theme has been retained. `procurement.html` adds the complete e-Procurement experience:
- 3-step token/slot booking
- Dynamic QR-style token and printable pass
- 6-stage live status stepper
- Dynamic estimated waiting time and vehicle throughput
- Geo-fenced 2 km check-in simulation
- Weather-aware scheduling for five mandis, covered shed routing and rescheduling
- Interactive Leaflet congestion map
- AI grain-quality scanner demonstration
- WhatsApp-style bot
- Hindi/English IVR voice demo using Web Speech API
- Offline emergency token and sync simulation
- MSP ticker
- DBT/PFMS/UTR status
- Digital J-Form generator
- Procurement officer "Call Next Token", audio chime and SMS simulation

This is a frontend prototype. Real weather, GPS, authentication, WhatsApp/SMS, PFMS/DBT, AI model, and secure server persistence still require backend/API integration.
