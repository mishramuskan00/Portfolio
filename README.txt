IMPORTANT
1. Keep the folder structure unchanged; project links use relative paths.
2. Open index.html locally and click each Live Demo to test the projects.
3. To update the existing Netlify site, deploy the CONTENTS of this folder (index.html and all project folders) as the publish directory.
4. Do not upload only index.html; all project folders and assets are needed for the demos to work.
5. The salon forms are front-end demos only. They do not authenticate users or save/send real appointments.
6. The Veloura slideshow uses externally hosted images, so an internet connection is needed to load those images.
