VELOURA STUDIO — HTML & CSS WEBSITE

FILES
- index.html: responsive salon homepage, automatic CSS-only hero image slideshow, services, story, contact/footer
- appointment.html: appointment request form
- login.html: client login form
- style.css: all styling and responsive layouts

HOW TO OPEN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use VS Code Live Server.
4. Use the navigation to open Login or Book a Visit.

HTML/CSS-ONLY LIMITATION
Forms use native HTML validation and a CSS :target confirmation panel. After valid submission, the page shows a submitted message. This is a front-end demonstration only: HTML/CSS cannot authenticate users, save appointments to a database, send emails, or retain submitted details. Do not use real passwords. A backend or JavaScript is needed for actual accounts/bookings.

Images and Google Fonts load from external URLs, so internet access is needed for those assets. Veloura Studio is a fictional brand; the reference websites were used only for broad inspiration.

SLIDESHOW
The homepage hero cycles through four images automatically using CSS animations. No JavaScript is used. Images load from Unsplash and need an internet connection.
